# 🖱️ AutoHold Pro

Программа для автоматического **зажатия клавиш мыши (ЛКМ / ПКМ)** с фиксацией на определённом окне (игры, Minecraft OneBlock, программы).

---

## ⚡ Главные возможности

1. **Мгновенный автозахват окна**:
   Вам не обязательно вручную искать окно в выпадающем списке. Просто наведите курсор на игру (например Minecraft) и нажмите **`Левый Alt` + `ЛКМ`** (или клавишу **`F6`**) — программа сама зафиксирует окно игры и сразу начнет зажатие!
2. **Аппаратный зажим мыши (`mouse_event`)**:
   Работает в любых 3D-играх (Minecraft GLFW/LWJGL, Roblox, шутеры, RPG), где обычные фоновые сообщения игнорируются движком.
3. **Умная фиксация на окне (Smart Lock)**:
   * Пока вы находитесь в окне игры — кнопка мыши физически зажата (копает блоки без остановки).
   * Если вы переключаетесь на браузер, YouTube или Discord — программа отпускает физическую мышь, чтобы вы могли свободно кликать и работать, продолжая удерживать фоновое состояние.
   * При возвращении в окно игры — зажим мгновенно возобновляется!
4. **Удобные горячие клавиши**: Поддержка как сочетания `Alt + ЛКМ / ПКМ`, так и быстрых клавиш в один клик `F6` / `F7`.

---

## ⌨️ Горячие клавиши

| Сочетание / Клавиша | Действие |
| :--- | :--- |
| **`Левый Alt` + `ЛКМ`** (или **`F6`**) | **Зажать / Отпустить Левую кнопку мыши** (копать / атаковать) |
| **`Левый Alt` + `ПКМ`** (или **`F7`**) | **Зажать / Отпустить Правую кнопку мыши** (ставить блоки / использовать) |
| **`F8`** или **`Esc`** | **Экстренная остановка** всех зажатий |

*При включении зажатия звучит высокий звуковой сигнал (бип), при выключении — низкий.*

---

## 🚀 Запуск программы

Просто запустите **`AutoHold.exe`** (или `AutoHold.pyw` / `run.bat`).
Установка Python не требуется (в `.exe` всё упаковано).

---

## ⚙️ Режимы работы

* **Умная фиксация на окне (Рекомендуется)**: держит зажатой кнопку, пока вы в игре. Если свернулись в браузер — мышь освобождается для работы.
* **Прямой постоянный зажим (Direct Hold)**: физически зажимает кнопку мыши намертво во всей системе Windows.
* **Фоновый режим (PostMessage)**: отправляет только фоновые оконные сообщения Win32.
* **Автокликер**: непрерывная серия быстрых кликов с настраиваемым интервалом (мс).
